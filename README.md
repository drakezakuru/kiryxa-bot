# Kiryxa — Telegram forum guard + chat persona

Бот для супергруппы с Topics: держит полезные дропы (ключи, промокоды, триалы, гайды)
в тематических ветках, оффтоп переносит в General с цитатой и ссылкой, а в общем
чате живёт как обычный участник — со своим характером, памятью и голосом.

Писался под одну приватку, но всё личное вынесено в конфиг: имя владельца, ID чата,
токен, модели. Клонируешь, заполняешь `config.json` — и это твой бот.

## Что умеет

- **Модерация веток.** В избранных темах оставляет дропы (ключи, промокоды, аккаунты,
  ссылки, БИНы, гайды), остальное переносит в General: карточка с автором, ссылкой на
  ветку и пост, оригинал удаляется только после успешной пересылки.
- **Зеркалирование.** Ценный дроп, появившийся в General, дублируется в ветку
  «Abuse and Keys» — без удаления из General.
- **Персона в чате.** Отвечает по имени/реплаю, помнит последние 50 реплик, сворачивает
  старое в заметки, держит стиль (без «чем могу помочь» и повторов).
- **Голос.** ElevenLabs с ротацией ключей: 13 голосов, переключатель в ЛС, скорость
  0.7–1.2. Если ключи в кулдауне — Edge-TTS, чтобы ответ не потерялся.
- **Медиа.** Фото и видео через локальный muse2api-мост; голосовые; стикеры и гифки
  по настроению с кулдаунами.
- **Vision.** Реакция на фото/гифку и короткий комментарий. Если отвечают на картинку
  с вопросом — бот отвечает на текст, а картинку получает как описание.
- **Веб-поиск.** Exa → Википедия → DuckDuckGo Lite, с маркерами недоверенных данных.
- **Безопасность.** Фильтры CSAM/вредоноса до генерации, приоритет правил в промпте,
  защита от prompt-injection через поиск и заметки.
- **ЛС.** Админам — живой диалог (текст или голос), выбор голоса кнопками,
  удаление сообщений по ссылке `t.me/c/...`.

## Требования

| Что | Версия | Зачем |
|---|---|---|
| Python | 3.10+ | рантайм, только stdlib |
| Telegram bot | — | токен от [@BotFather](https://t.me/BotFather), права админа в группе |
| LLM API | — | любой OpenAI-совместимый `/chat/completions` (Mercury, Gemini-мост и т.п.) |
| ElevenLabs ключи | опционально | голос; можно жить на Edge-TTS |
| muse2api | опционально | фото/видео; без него останутся текст и голос |
| Exa API | опционально | веб-поиск; без него Википедия + DDG |

Внешних Python-пакетов нет: всё на `urllib`, `sqlite3`, `threading`. Для Edge-TTS
нужен пакет `edge-tts` — если его нет, голос уйдёт в muse2api или пропадёт.

## Установка и запуск

### Linux / macOS

```bash
git clone https://github.com/<твой-ник>/kiryxa-bot
cd kiryxa-bot
cp config.example.json config.json     # заполни токен и ID чата
./start.sh
```

### Windows

```bat
start.bat
```

`start.bat` сам создаст venv (пакеты не нужны, но venv пригодится), скопирует
`config.example.json` в `config.json` и запустит бота.

### Как подключить к группе

1. Добавь бота в супергруппу с включёнными **Topics**.
2. Выдай права администратора: *Delete messages* и *Manage topics*.
3. В `config.json` укажи `private_chat_id` — ID этой группы (например, `-1001234567890`).
4. В нужных ветках вызови `/guard smart` (или `/panel` и настрой кнопками).

## Конфигурация

| Ключ | Обязателен | Что значит |
|---|---|---|
| `bot_token` | да | токен от BotFather |
| `admin_tg_ids` | да | ID админов бота (команды, панель) |
| `private_chat_id` | да | ID твоей супергруппы: только там бот модерирует |
| `owner_name` / `owner_username` / `owner_tg_ids` | нет | кто для бота «создатель»: к нему особое обращение |
| `ai_api_url` / `ai_api_key` / `ai_model` | да | OpenAI-совместимый LLM |
| `fallback_api_*` | нет | резервная модель |
| `muse_api_url` | нет | мост для фото/видео (по умолчанию `127.0.0.1:12001`) |
| `muse_video_enabled` | нет | вкл/выкл видео (у Muse рендер бывает нестабилен) |
| `elevenlabs_keys_file` | нет | файл со списком ключей ElevenLabs, по одному на строку |
| `elevenlabs_voice_id` | нет | стартовый голос (дальше переключается в ЛС) |
| `vision_api_url` / `vision_api_key` | нет | мультимодальная модель для фото/гифок |
| `exa_api_key` | нет | веб-поиск |
| `sticker_sets` | нет | паки стикеров, которые бот индексирует по эмодзи |
| `data_dir` | нет | где БД и кэши (по умолчанию `data`) |

Все секреты — только в `config.json`, он в `.gitignore`. В коде дефолтов с ключами нет.

## Как это работает

```
сообщение ──► маршрутизация (ветка / General / ЛС / внешний чат)
                 │
                 ├─ ветка: классификатор → keep  → остаётся
                 │                       → move  → карточка в General → удаление
                 │
                 ├─ General: зеркало дропов в «Abuse and Keys» + персона
                 │
                 └─ персона: память (50 реплик + заметки) → LLM → ответ
                              ├─ голос (ElevenLabs → Edge-TTS)
                              ├─ стикер/гифка по настроению
                              └─ фото/видео (muse2api)
```

Медленные вещи (LLM, поиск, TTS, генерация) идут в пул потоков с локом на ветку:
polling не стоит, порядок ответов сохраняется. Память — SQLite (`chat_memory`,
`chat_notes`, `person_notes`, `settings`), старые реплики сворачиваются в заметки
каждые 12 ходов.

## Известные ограничения

- **Muse (фото/видео) — внешний мост.** Видео у Muse периодически виснет и блокирует
  аккаунт: в боте есть предохранитель (одна попытка, потом пауза и рестарт моста),
  но если видео критично — лучше другой провайдер.
- **ElevenLabs ключи из пачек живут недолго.** Клиент ротирует пул и запоминает
  кулдауны, но при полном отказе остаётся Edge-TTS.
- **Классификатор ошибается на медиа без подписи** — такое уходит в General.
  Иммунитет админов (`/adminbypass`) включён по умолчанию.
- **Память ограничена** 50 репликами в промпте + заметки; дальше — только заметки.
- **Реакции/гифки вероятностные** — бот может не отреагировать или выбрать не то
  настроение; кулдауны 25 с на стикер и 90 с на гифку.
- **Форум-топики обязательны** для режима модерации; в обычных группах бот работает
  только как персона.

## Частые проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| Бот молчит в группе | не админ или выключен Privacy Mode | сделай админом или `/setprivacy` → Disable у BotFather |
| Не переносит оффтоп | `private_chat_id` не совпадает с чатом | проверь ID группы в конфиге |
| Голос не приходит | все ключи ElevenLabs в кулдауне | добавь ключей в файл, проверь `/voices` |
| Фото не генерится | muse2api не запущен/завис | перезапусти мост, проверь `/health` |
| Отвечает не в тему | история/поиск подмешали контекст | `/status`, сократи память, проверь промпт |
